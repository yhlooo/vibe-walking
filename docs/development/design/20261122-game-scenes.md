# 游戏场景、地图尺寸和创作流程

本文更新[一期设计](20261122-phase-one.md)中的页面流程、地图尺寸、竖直边界和试玩会话约定。

关卡存档、创作入口和 Agent 交互的后续变更见[本地关卡库设计](20261122-local-level-library.md)。

## 场景与设置

默认路由进入主界面，提供「关卡」「创作」和「设置」入口。左上角的角色标志返回主界面。游玩和创作场景右上角提供暂停菜单，包含「继续」「主界面」「设置」。设置场景沿用同一暂停机制，返回时恢复当前场景。

关卡卡片显示地图预览、通关状态、首次通关时间和最佳通关耗时。一次尝试从第一条发给 Agent 的玩家消息开始计时，到踩下红色按钮结束。模型响应和暂停期间的等待均计入耗时。重开或离开关卡结束本次尝试。每个内置关卡在浏览器本地保存首次通关时间和最短耗时，旧存档的首次通关时间继续有效，完成一次计时通关后才显示最佳耗时。

地图尺寸以行 × 列表示，分别为小（10 × 15）、中（20 × 30）和大（32 × 48）。内置关卡的尺寸由各自定义的网格决定，首关采用小号。创作地图的尺寸随草稿和 YAML 保存，可独立选择。继续接受既有的 9 × 16 草稿和关卡文件。调整地图时按重力方向对齐地图，再移动超出范围的出生点和按钮。创作中缩小地图若会裁掉已画地形或按钮，需确认后应用。

主界面使用 SVG 背景，关卡列表预览使用带斜面装饰的渐变。游玩和创作使用纯垂直渐变作为 Canvas 背景，按地图长宽比显示，绘制分辨率随显示尺寸和设备像素比调整。Agent 的读屏工具继续生成同一比例、固定高度的 PNG。Vibe 方块轮廓的圆角半径为自身宽度的 2%，碰撞范围仍为完整方块。

窄屏主界面将标题和菜单靠左布置，背景从右下定位并限制窄长视口的放大比例，使右侧的 Vibe 和按钮保持在画面内。

## 同屏创作与游玩

创作进入时自动加载草稿、关卡运行和对话。画布显示运行角色和可编辑网格，画笔始终可用。地形、出生点、尺寸或物理参数提交后，从新地图的出生点开始运行。名称和 Agent 提示词可直接更新，下一条消息使用新的提示词。草稿缺按钮或支撑时仍可试玩和编辑，导出仍需通过原有可玩校验。

打开「手动控制」后从出生点开始，暂停接受 Agent 的动作和新消息。首次有效移动或跳跃前，角色和动作记录均保持初始状态。第一次输入之后，每个物理步均纳入录制，包括操作间的等待。关闭开关后 Agent 可以接手当前角色，已录动作仍可复制。手动录制保留在当前运行，重开或新地图载入时开始新的录制。

## 边界和对话

地图顶边阻止角色向上穿出，负重力下可充当角色的支撑面。角色整个离开底边时判定死亡并停止运行，重开使角色返回出生点。

关卡重新开始、切换控制方式或切换模型时，取消尚未完成的 Agent 请求和动作序列。浏览器页面存续期间，每个内置关卡和创作场景分别保留对话及工具事件。重开和导航后继续使用当前场景的历史。更换模型协议时，以既有文字对话重建发送给新协议的上下文，工具事件仍可在聊天栏查看。「清空历史」会清除当前场景的聊天记录及模型上下文。

聊天历史和输入栏共用侧栏空间。拖动中间的分隔线，或聚焦后使用方向键，可以调整两部分高度。
