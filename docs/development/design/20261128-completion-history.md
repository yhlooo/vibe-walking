# 通关记录和继续游戏

## 游玩状态

正式游玩的世界、动作队列、计时和对话由当前页面的场景持有。进入关卡从出生点开始，初次发送玩家指令时开始计时，踩下红色按钮时结束计时。场景卸载时销毁本局状态。暂停菜单及设置页可以恢复同一个仍挂载的场景。创作试玩沿用编辑器的运行期状态。

每次进入正式游玩向服务登记关卡 ID，内置和自建关卡都可成为最近关卡。首页的「继续游戏」在点击后重新读取服务记录与目录，并从最近关卡的出生点开始新一局。最近关卡缺失或不可游玩时，从首个尚未通关的内置关卡开始。内置关卡均已通关时回到首关。场景的推进、坠落、重置、通关及退出都不更新最近关卡。

## 服务端记录

`progress.json` 保存最近关卡 ID、各关首次通关时间和最佳耗时，以及各次独立的通关记录。每条通关记录包含关卡物理版本、尝试 ID 和服务端确认时间。最近一次在物理步中发出移动或跳跃输入的模型是该次通关的归属模型。如关卡可以自动通关且从未执行模型动作，模型字段缺省。未发出玩家指令的通关可以省略用时。关卡列表可展开查看逐次记录。

同一服务内，最近关卡登记和通关提交由关卡存储加锁串行处理，每次从当前文件合并后原子替换。最近关卡按服务端受理顺序更新，旧页面的通关提交只追加成绩。尝试 ID 由页面生成，同一关卡内同 ID 的重复提交返回已有记录。自建关卡的物理版本已变化时，旧版本的新成绩提交返回冲突。

首次读取或更新旧版文件时，保留已知的通关汇总和最近内置关卡，清理旧版未完成尝试。浏览器旧存储通过已有迁移接口合并。旧数据中的首次时间与最佳耗时可能来自不同尝试，因此只保留在汇总中。
