# 对话框输入区布局

游玩与编辑器试玩共用对话框。消息列表占据输入区上方的可用空间，历史消息较多时在列表内滚动。列表与输入区之间取消分隔线和高度调整控件。

输入区背景贴合对话框边缘，顶部为直角，位于对话框底部时由对话框外壳裁出下方圆角。文字区随换行向上伸展或回缩，最少三行、最多八行，超出后在文字区内滚动。聚焦文字区时沿用原有边缘样式。

底部操作栏独立于文字区。模型参数使用比模型名称更暗的次要文字色。发送和停止按钮共用同一位置。空闲时显示圆形上箭头发送按钮，运行时显示带方块图标的停止按钮。当前回合停止或结束后才可发送下一条消息。编辑器显示动作记录时，记录面板位于输入区下方。

自动伸缩的浏览器支持与兼容实现见[文本框随内容调整高度](../research/20261128-textarea-sizing.md)。
