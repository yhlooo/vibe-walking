# Vibe 对话与模型设置

## 设置与游玩入口

用户名、模型配置随本地数据目录的 `settings.json` 保存。设置接口支持独立更新用户名或模型。游戏路由在创建关卡运行之前检查用户名，未设置时打开设置弹窗。用户名保留字符和空白，最多 20 个 Unicode 码点，空字符串表示未设置。默认及关卡自定义 System Prompt 在发送前替换 `{{user}}`。内置中断提示和压缩指令沿用该占位符，输入框中的文字原样发送。

模型连接表单依次显示协议、Base URL、API Key、模型、上下文长度和思考长度。聚焦模型字段时，浏览器向本地服务的 `POST /api/v1/models` 发送表单中的连接信息。服务按协议读取上游列表，仅返回模型 ID。密钥留空且协议与规范化后的地址都与已保存连接相同时，服务复用已保存的密钥。编辑连接或关闭表单时取消查询。输入模型 ID 时，列表按不区分大小写的子串筛选。选择建议会填入该模型 ID，直接保存则使用输入值。

上下文长度在界面上以 K 输入，1 K 等于 1000 token，使用 `maxInputToken` 保存实际 token 数。旧配置默认 1000 K。思考长度使用同一个输入框选择或输入，展开列表始终显示默认、`low`、`medium`、`high`、`xhigh`、`ultra`。默认对应空值。OpenAI Chat Completions 使用 `reasoning_effort`，OpenAI Responses 使用 `reasoning.effort`，Anthropic Messages 使用 `output_config.effort`。官方端点将 `ultra` 映射为 `max`，兼容端点按设置值发送。模型支持情况取决于所使用的上游。

Ollama Chat 的默认 Base URL 为 `http://localhost:11434`。代理在 Base URL 后追加 `/api/chat` 或 `/api/tags`。本地 Ollama 可留空密钥。Ollama 思考长度映射到 `think`，手输 `true` 或 `false` 分别映射为布尔值，级别使用字符串。

## 流式回合与中断

浏览器中的协议适配器请求流式生成，Go 代理将已收到的 SSE 或 Ollama NDJSON 数据及时刷新给浏览器。适配器逐段更新对话框里的思考和回复，思考通过可展开区域呈现。工具必须等回复确认完成后才执行，完整的工具调用、推理块和工具结果按协议保留。浏览器对连续 65 秒没有收到响应数据的请求结束等待。

游戏回合的每次模型请求都提供游戏工具，由模型决定是否调用。每次执行一个工具调用后，将结果随历史发回模型，再等待下一条响应。模型完成一条没有新工具调用的响应时，本轮结束。单轮工具往返次数不限，玩家可随时中断，模型请求失败时结束本轮并显示错误。

每轮对话有独立的取消信号，网络读取和动作序列共享它。中断后保留已收到的回答和思考。流未完成时把它们写为助手文本，完整工具调用仍配有中断结果，便于模型了解动作可能只执行了一部分。下一条用户消息带一次性 `<system-info>`，其中填入当前用户名。已执行的物理步骤保留，物理系统继续处理重力和惯性。

## 上下文压缩

发起游戏生成前根据历史和提示词估计输入 token，用最近一条对应模型的上游用量校准。达到阈值时，用相同的模型协议发起禁用工具的流式摘要请求。优先压缩较早的回合，保留当前指示。若单轮工具往返继续积累，则压缩当轮已完成的历史并再次附上原始指示。摘要读取工具参数和结果，历史截图以文字标记表示。聊天面板保留消息。压缩失败时显示原因，使用原上下文继续当前回合。

外部接口依据见[流式接口调查](../research/20261122-llm-streaming.md)及[模型列表与 Ollama Chat 接口调查](../research/20261123-model-discovery-and-ollama.md)。
