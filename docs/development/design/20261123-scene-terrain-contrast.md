# 游戏画面地形对比度

原配色的实心块主体是 `#29263e`，与原背景渐变中的一段几乎同亮。地形高光只画在上沿，墙面侧边和平台下沿主要靠块面与背景的亮度差来辨认。

## 场景配色

背景从近黑的 `#030207` 过渡到 50% 处的 `#100e1f`，底端为 `#161227`。中点和底端沿用上一轮预览的颜色，使背景下半部保留该轮预览的亮度。实心块主体用 `#332f47`，砖缝用 `#1a192c`，上沿用 `#72639c`。基础渐变与块面的最低亮度对比约为 1.42∶1，出现在渐变底端。

游玩、创作、关卡预览和 `ReadScreen` 共用[场景绘制逻辑](../../../src/render/scene.ts)。画面顶边直接呈现场景内容，地图边界的碰撞规则见[场景与边界设计](20261122-game-scenes.md#边界和对话)。关卡预览在基础渐变右侧绘制一片淡紫色斜面，斜边的位置和方向沿用首页布局。`ReadScreen` 生成 512 像素高的 PNG。首页使用独立的 [SVG 背景](../../../src/render/backdrop.svg)。

## 验证方式

使用相同关卡状态生成新旧 `ReadScreen` 截图，对照单格障碍、高处的竖墙、悬空平台底面和地面缺口。用缩小后的灰度图检查地形轮廓，再让目标小模型回答相同的地形定位问题，比较回答与实际格位的一致性。亮度对比用于筛选配色，模型识别效果以实测为准。
