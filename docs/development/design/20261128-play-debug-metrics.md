# 游玩页模型调用统计

游玩页接受页面 URL 的 `?debug=true`，也接受游玩 hash 路由后的 `?debug=true`。面板在游玩区下方单行显示，窄屏可横向滚动。通过游玩页的「下一关」链接时保留调试开关。

打开调试面板后从零开始统计。刷新页面、切换关卡、离开后重新进入该关或清空聊天历史都会重新累计。每次发出模型请求时增加 `Turn`，包括工具结果的续请求和上下文压缩请求。成功完成的响应累加服务端报告的 Token，失败或中断的请求保留轮数。

累计缓存命中率按 Token 加权，以报告了缓存命中数的请求为样本。最近一轮命中率和输出速率取最近完成的响应，缺少数据时显示 `—`。Ollama 优先使用服务端的生成时长，其他情况使用客户端从发起请求到读完响应的耗时，得到端到端的平均输出速率。

供应商字段见[流式模型调用的统计字段](../research/20261128-model-request-metrics.md)。
